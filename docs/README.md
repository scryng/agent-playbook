# Project documentation

This folder holds **meta documentation for evolving `agent-playbook` itself** (commit style, branch naming, local setup).

It is **not** part of the portable playbook core. When this repository is cloned into a host project and wired for Agent Workflow Orchestration, orchestrators and agents **must ignore** everything under `docs/`. Host project conventions apply instead.

See the [README](../README.md#project-documentation-vs-playbook-core) for the coupling rule.
